# Carpeta de Assets Públicos

Guarda aquí las imágenes, logos y fotos estáticas del frontend.

Todo archivo que pongas aquí se referencia directamente en CSS y componentes mediante la ruta `/assets/nombre-archivo.ext`.

Por ejemplo:
- Si guardas `taller.jpg` aquí (`frontend/public/assets/taller.jpg`),
- En CSS lo usas como: `background-image: url('/assets/taller.jpg');`
